# Security & Responsible Disclosure

This repository hosts a synthetic, browser-only, evaluation demonstration. It does not expose private HRONOAZA source code or production infrastructure.

**Do not send credentials, private source archives, customer information, security tokens, or sensitive evidence files** through public GitHub issues or the public demo.

For a potential vulnerability or accidental sensitive disclosure, contact **hronoaza00@gmail.com** privately with a minimal reproduction and affected file or version. Avoid publicly posting exploit details or secrets before a coordinated response.

This project does not offer a bug bounty, security SLA, or certified security assurance. Commercial security and support arrangements require a separate contract.
